❓ Como jogar

PC

W A S D mover • Mouse olhar (clique p/ travar) • Espaço pular • Shift correr • E inventário • 1–9 hotbar • Botão esq. quebrar • Botão dir. colocar • C agachar • F voar (criativo) • Esc pausa • V trocar câmera

Celular

Joystick esquerdo = mover • arrastar lado direito = câmera • botões ⬆ quebrar/ colocar/agachar/inventário. Multitoque suportado.

Sobrevivência

Quebre madeira → tábuas → bancada → ferramentas. Use forno (carvão como combustível) para fundir ferro/ouro. Coma para recuperar vida. À noite fuja ou lute com espada. Morte: você renasce no spawn e mantém metade dos itens (dificuldade paz/normal) — configurable na tela de morte não; regra fixa exibida.

Salvar

Salvamento automático a cada 30s + botão na pausa. Mundos ficam em IndexedDB no próprio navegador. Exporte JSON para backup.
